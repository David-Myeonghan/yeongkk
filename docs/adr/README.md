## 언제 쓰나

둘 중 하나면 ADR로 쓴다. 아니면 장부 한 줄로 끝낸다.

- 뒤집으면 PR 하나로 안 끝난다.
- 웹 · 앱 · 서버 중 둘 이상을 건드린다.

## 칸

파일 이름은 `NNNN-짧은-영어-이름.md`다. 맨 위에 결론 두 줄을 두고, 그 아래에 이 순서로 쓴다.

- 상태: 제안 / 채택 / 대체됨 → 번호. 정한 날, 사후 기록이면 적은 날, 확신(높음 / 중간 / 낮음)
- 배경: 무엇이 필요했고 어떤 제약이 있었나
- 결정 기준: 후보를 무엇으로 비교했나
- 후보: 둘 이상. 후보마다 한 줄로 버린 이유
- 결정: 고른 후보
- 결과: 좋음 / 나쁨. 잃는 것을 숨기지 않는다
- 확인 방법: 이 결정이 지켜지는지 무엇이 검사하나(테스트 파일, 검사, 「사람」, 「아직 없음」)
- 다시 볼 조건: 어떤 일이 생기면 다시 정하나
- 근거: PR · 커밋 · 문서

기록에 없는 칸은 지어내지 않고 「David가 적는다」로 둔다.

## 고칠 때

옛 ADR은 지우지 않는다. 결정을 뒤집으면 옛 ADR의 상태를 「대체됨 → 번호」로 바꾸고 새 번호로 새 ADR을 쓴다.
확신과 사실이 바뀌면(예: 실기기에서 확인했을 때) 해당 칸만 고치고 날짜를 남긴다.
