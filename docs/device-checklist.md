# 실기기 점검표

> TL;DR: 이 앱은 실제 폰에서 한 번도 돌려 본 적이 없다. 아래 표는 앱 PR #17(웹뷰 껍데기 · 공유 · 진동), #18(광고), #19(알림)의 설명과 `app/README.md`, `docs/bridge-matrix.md`가 「확인하지 못했다」고 적은 것을 한 표로 모은 것이다. 비어 있는 iOS · 안드로이드 칸은 주인이 폰으로 직접 채운다.

상태: 초안(2026-11-25, AI가 씀). 모든 결과 칸이 비어 있다. 이 문서를 쓴 쪽은 어떤 칸도 확인하지 않았다.

## 쓰는 법

- 칸에는 「통과」 「실패(무엇이 일어났나)」 「해당 없음(이유)」 「재현 못 함」 중 하나와 날짜를 적는다.
- 맨 위에 기기 모델과 OS 버전을 적는다. iOS: `______`, 안드로이드: `______`.
- 빌드는 `docs/release.md` 6단계의 `preview` 빌드다. 광고 줄(D26~D31)만 광고 빌드가 필요하다.
- 출처 칸: `#17` · `#18` · `#19` = 그 PR이 「확인하지 못했다」고 적은 항목, `rm` = `app/README.md`의 「확인하지 못한 것」, `bm` = `docs/bridge-matrix.md`의 「실기기에서 확인할 것」, `새로` = 이번 출시 준비에서 새로 생긴 항목(아이콘 · 스플래시 등).

## 목록에서 뺀 것

- 원격 푸시: 쓰지 않는다. 쓰게 되면 항목을 새로 만든다.
- 알림을 누르면 특정 화면으로 가기, 알림 시각 고르기: 아직 만들지 않았다(`app/README.md`의 「일부러 아직 안 한 것」).
