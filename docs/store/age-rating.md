# 연령 등급 답 초안

> TL;DR: 앱에 폭력, 성적 내용, 도박, 약물 장면이 없다는 전제로 가장 낮은 등급이 나올 것으로 본다. 다만 단어(신조어)가 게시되기 전이라, 단어 내용은 게시 뒤 다시 확인해야 한다. 모두 「제안」이다.

상태: 초안(2026-11-25, AI가 씀). David 확인 전.

Apple 연령 등급 질문지는 「내용 설명」(빈도를 고른다), 「앱 안 제어와 기능」, 「도박 유사 활동」 같은 묶음으로 되어 있다(출처: https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating/ , 2026-11-25에 읽음). 이 페이지는 질문 하나하나와 등급 값 전체 목록을 주지 않았다. 아래는 앱 내용을 묶음별로 적은 것이다. 실제 질문 문구는 App Store Connect 화면에서 보고 옮긴다.
Apple 지침 2.3.6은 「연령 등급 질문에 솔직하게 답하라」고 한다(https://developer.apple.com/app-store/review/guidelines/).

## 답 (모두 제안)

| 묶음 | 답 | 이유 |
| --- | --- | --- |
| 폭력(만화 · 사실적) | 없음 | 그림 · 영상이 없다. 글과 보기뿐이다 |
| 성적 내용 · 노출 | 없음 | 단어 수록 기준이 특정 집단 비하와 금지어를 뺀다(`docs/word-criteria.md`). 다만 신조어 중에는 어른 말투가 섞일 수 있어서, 게시 단어를 훑어 본 뒤 확정한다 |
| 욕설 · 저속한 말 | 게시 단어를 훑은 뒤 확정 | 금지어 목록 파일(`config/ko-KR/banned.txt`)이 지금 비어 있다. 신조어에는 속된 말이 들어올 수 있다. 들어오면 「가끔」 쪽으로 답한다 |
| 약물 · 술 · 담배 | 없음 | 단어 예문에 나올 수 있으나 장면이 아니다. 게시 단어를 훑은 뒤 확정 |
| 공포 · 무서운 내용 | 없음 | |
| 도박 · 도박 유사 · 뽑기 상자 | 없음 | 재화도 뽑기도 없다 |
| 의학 · 건강 정보 | 없음 | |
| 사용자가 만든 글 | 보낸 글이 다른 사용자에게 보이지 않는다 | 「요즘 들은 말 알려 주기」는 서버에 저장될 뿐 다른 사람에게 보여 주지 않는다. 운영자만 본다 |
| 사용자끼리 채팅 · 메시지 | 없음 | |
| 제한 없는 웹 접근 | 없음(제안) | 웹뷰는 앱 자기 웹 주소만 연다. 다른 주소는 기기 브라우저로 보낸다(`app/src/navigation.ts`). 공유 링크 같은 바깥 링크가 생기면 다시 본다 |
| 연령 확인 · 부모 제어 | 해당 없음 | 계정이 없다 |
| 광고 | 광고 빌드에서만 「있음」 | 광고 없는 빌드에는 SDK가 없다. 광고 빌드는 배너 하나다 |

## 대상 연령

개인정보 처리방침과 스토어 대상 연령은 16세 이상이다(주인 결정). 연령 등급은 내용으로 계산되는 값이고 대상 연령은 따로 정한다. 둘이 다를 수 있다.
Apple은 「Made for Kids」 범주를 고를 수 있는데, 이 앱은 고르지 않는다. 그 범주를 고르면 추적과 광고에 더 엄격한 규칙이 붙는다(이 문서에서 그 규칙은 확인하지 않았다).
Google Play는 대상 연령대를 따로 고르는 칸이 있다. 16세 이상(청소년 이상) 구간만 고른다. 아이들이 포함되는 구간을 고르면 정책이 달라진다(이 페이지는 확인하지 않았다).
