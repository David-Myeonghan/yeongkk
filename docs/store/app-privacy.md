# 개인정보 신고 답 초안 (Apple App Privacy · Google Data safety)

> TL;DR: 광고 없는 빌드는 「익명 번호 · 행동 기록 · 보낸 글」을 모은다고 답하고 추적은 없다고 답한다. 광고 빌드는 여기에 AdMob이 모으는 것(IP, 광고 식별자, 광고 본 기록 등)을 더한다. 전부 「제안」이고, 최종 답은 David가 스토어 화면에서 정한다.

상태: 초안(2026-11-25, AI가 씀). David 확인 전. 어느 양식에도 아직 제출하지 않았다.

근거는 코드다. 방침(`docs/privacy.md`)과 같은 사실을 쓴다. 코드가 바뀌면 이 문서도 고친다.
읽은 공식 페이지(2026-11-25):
- Apple App Privacy 안내: https://developer.apple.com/app-store/app-privacy-details/
- Google Play 데이터 보안 양식 안내: https://support.google.com/googleplay/android-developer/answer/10787469
- AdMob iOS 개인정보 공개 안내: https://developers.google.com/admob/ios/privacy/data-disclosure
- AdMob Android 데이터 공개 안내: https://developers.google.com/admob/android/privacy/play-data-disclosure

## 코드가 실제로 보내는 것 (두 빌드 공통)

- 익명 번호(기기에서 만든 무작위 값), 언어(ko-KR), 열린 곳(앱/브라우저), 앱 버전, 받은 시각.
- 행동 이름 여덟 가지와 딸린 값(`quiz-core/events.ts`, 값은 `docs/privacy.md`에 모두 적었다).
- 「요즘 들은 말 알려 주기」 글(1~20자).
- 위치, 연락처, 사진, 이름, 이메일, 전화번호, IP, User-Agent는 서버가 받지 않는다(`tools/privacy/privacy.test.ts`가 서버가 읽는 머리글과 표 칸을 지킨다).
- 위 값을 앱이 따로 암호화하지는 않는다. 보낼 때는 HTTPS다(스토어 빌드는 https 주소만 연다. `app/src/releaseCheck.ts`).

## A. 광고 없는 빌드 (기본)

### Apple App Privacy 질문 (제안)

Apple의 「수집」 정의는 「기기에서 보내서 요청을 처리하는 시간보다 오래 우리가 접근할 수 있는 것」이다. 서버가 저장하므로 모두 수집이다.

| 데이터 종류 | 수집? | 사용자와 연결? | 추적에 사용? | 쓰는 목적 | 이유 |
| --- | --- | --- | --- | --- | --- |
| 식별자 > 기기 ID | 예 | 예(보수적) | 아니오 | 분석 | 익명 번호. 사람 이름과는 이어지지 않지만 같은 기기의 기록을 이어 준다. Apple 안내가 「기기 등으로 연결되면 연결로 본다」고 해서 연결 「예」로 둔다. 아니오라고 답할 근거가 약하다 |
| 사용 데이터 > 제품 상호작용 | 예 | 예(보수적) | 아니오 | 분석, 앱 기능 | 행동 기록(문제에 답함, 판을 끝냄, 공유함) |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 | 예 | 예(보수적) | 아니오 | 기타(단어 후보 검토) | 「알려 주기」 글. 익명 번호와 함께 저장된다 |
| 진단 > 성능 데이터 | 경계 | | | | `bridge_hello`의 걸린 시간(밀리초)은 앱 연결 속도다. 앱 시작 시간 같은 것을 재는 값은 아니다. 보수적으로 가려면 「성능 데이터, 분석」으로 넣는다 |
| 그 밖의 모든 종류(연락처 정보, 위치, 구매, 건강, 금융, 검색 기록, 탐색 기록, 민감 정보, 충돌 데이터 등) | 아니오 | | | | 코드가 모으지 않는다 |

「추적」은 앱이 모은 데이터를 제3자 데이터와 합쳐 타깃 광고나 광고 측정에 쓰거나 데이터 중개인에게 넘기는 것이다(Apple 정의). 이 빌드는 그런 일을 하지 않는다 → 추적 없음. 그래서 App Tracking Transparency 창도 없다(광고 없는 빌드에는 추적 문구 설정이 들어가지 않는다. `app/app.config.ts`).
개인정보 처리방침 URL은 필수다(Apple 안내).

### Google Play 데이터 보안 양식 (제안)

양식은 앱 하나에 하나이고 모든 버전에 걸린다(Google 안내). 광고 빌드를 한 번이라도 올릴 계획이면 B 표를 기준으로 쓴다.

| 질문 | 답 | 이유 |
| --- | --- | --- |
| 데이터를 수집하나 | 예 | 서버로 보낸다 |
| 제3자와 공유하나 | 아니오 | Cloudflare는 우리를 위해 처리하는 서비스 제공자다(Google 안내: 서비스 제공자 전송은 「공유」가 아니다) |
| 기기 또는 기타 ID | 수집 | 익명 번호. 목적: 분석 |
| 앱 활동 > 앱 상호작용 | 수집 | 행동 기록. 목적: 분석 |
| 앱 활동 > 기타 사용자 생성 콘텐츠 | 수집 | 「알려 주기」 글. 목적: 앱 기능 또는 기타 |
| 전송 중 암호화 | 예 | HTTPS |
| 삭제 요청 방법 | 예 | 방침에 적은 이메일 요청. Google 안내: 요청 절차를 두거나 90일 안에 자동 삭제해야 「있음」으로 답할 수 있다. 이 서비스에는 자동 삭제가 없으므로 요청 절차(문의처)가 그 근거다. 문의처가 자리표시인 동안은 이 답을 낼 수 없다 |
| 개인정보 처리방침 | URL 필수 | `https://<도메인>/privacy/` |
| 필수 · 선택 | 사용자가 끌 수 없다 | 행동 기록을 끄는 설정이 없다(`docs/privacy.md`) |

## B. 광고 빌드 (AdMob 포함)

A 표에 아래를 더한다. AdMob SDK가 자동으로 모으는 것이다(위 AdMob 안내 두 페이지 기준).

### Apple App Privacy (제안)

| 데이터 종류 | AdMob이 모으는 것 | 추적에 사용? | 목적 |
| --- | --- | --- | --- |
| 식별자 > 기기 ID | 광고 식별자(IDFA, 허용했을 때) 또는 앱 단위 식별자 | 예(허용한 사용자에 한해 광고에 쓴다. 제안: 「예」로 답하고 추적 허용 창을 쓴다) | 제3자 광고, 분석 |
| 사용 데이터 > 광고 데이터 | 본 광고 | 예 | 제3자 광고, 분석 |
| 사용 데이터 > 제품 상호작용 | 앱 실행, 탭 등 | 예 | 제3자 광고, 분석 |
| 위치 > 대략적 위치 | IP로 짐작한 대략 위치 | 아니오 | 제3자 광고 |
| 진단 > 충돌 · 성능 데이터 | 충돌 기록, 시작 시간, 멈춤 비율 | 아니오 | 분석 |

- iOS 추적 허용 창 문구는 `app/app.config.ts`의 `ADS_TRACKING_TEXT`다. 주인이 검토한다(`app/README.md`의 「스토어 심사 때 볼 것」도 같은 검토를 요구한다).
- AdMob 안내는 「사용자와 연결」 여부를 칸마다 적지 않는다(Google 안내 페이지). 성능 데이터만 「사용자와 연결」로 적는다. 나머지는 보수적으로 「연결」로 답한다.

### Google Play 데이터 보안 (제안)

| 데이터 | 수집 | 공유(AdMob/Google) | 목적 |
| --- | --- | --- | --- |
| 기기 또는 기타 ID(광고 ID, 앱 세트 ID) | 예 | 예 | 광고, 분석, 사기 방지 |
| 대략적 위치(IP에서) | 예 | 예 | 광고, 분석, 사기 방지 |
| 앱 활동(앱 상호작용) | 예 | 예 | 광고, 분석, 사기 방지 |
| 앱 정보 및 성능(진단) | 예 | 예 | 광고, 분석, 사기 방지 |

- 광고 SDK가 광고 ID를 쓰므로 Play Console의 「광고 ID」 선언은 「예」, 사용 목적은 광고다. 플러그인이 `AD_ID` 권한을 더한다(`app/README.md`의 「스토어 심사 때 볼 것」). Google 안내는 광고 ID 수집을 매니페스트로 막을 수 있다고만 쓰고 권한 이름은 적지 않았다. 권한 이름은 빌드한 매니페스트에서 확인한다.
- Play Console의 「광고 포함」 표시는 「예」다.
- 유럽 등 동의가 필요한 지역: AdMob 콘솔의 개인정보 및 메시지 메뉴에서 GDPR 동의 메시지와 iOS ATT 메시지를 켜야 한다. 이것은 David의 AdMob 계정에서만 할 수 있다(`app/README.md`).
