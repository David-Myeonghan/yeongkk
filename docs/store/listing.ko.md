# 스토어 등록 초안 (한국어)

> TL;DR: 스토어 입력칸에 붙여 넣을 글 초안이다. 「제안」은 AI가 낸 안이고, 「David가 적는다」는 주인만 줄 수 있는 값이다.
> 글자 수 한도는 Apple App Store Connect 도움말 기준이다. 출처: https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/ (2026-11-25에 읽음)

상태: 초안(2026-11-25, AI가 씀). David 확인 전. 아직 아무 스토어에도 내지 않았다.

## 쓰지 않는 것

다운로드 수, 별점, 수상, 사용자 수, 「인기」 같은 말은 쓰지 않는다. 그런 사실이 없다.
단어 개수도 쓰지 않는다. 지금 게시된 단어가 0개라서다. 게시 단어가 채워진 뒤 숫자를 확인하고 적는다.

## 이름과 부제

| 칸 | 값 | 한도 | 출처 |
| --- | --- | --- | --- |
| 앱 이름 | 뭔말이야 (4자) | 30자 | 제안. 상표 확인 전이다. 아래 「David가 적는다」 참고 |
| 부제 | 요즘 신조어, 퀴즈로 맞혀 봐요 (17자) | 30자 | 제안 |
| 홍보 문구 | 아래 | 170자 | 제안 |
| 키워드 | 아래 | 100바이트 | 제안 |
| 카테고리 | 1순위 게임 > 퀴즈, 2순위 교육 | | 제안 |
| 지원 URL | David가 적는다 | 필수. 실제 연락처로 이어져야 한다 | David가 적는다 |
| 마케팅 URL | David가 적는다(웹 퀴즈 주소) | 선택 | David가 적는다 |
| 개인정보 처리방침 URL | `https://<도메인>/privacy/` | 필수 | 도메인은 David가 정한다. 페이지는 이 저장소의 `web/public/privacy/index.html` |
| 저작권 | `<연도> <이름>` | 필수 | David가 적는다 |

Google Play는 앱 이름 30자, 짧은 설명 80자, 긴 설명 4000자다(Play Console 입력칸 기준. 이 도움말 페이지는 읽지 못했다. 입력할 때 화면 한도를 따른다).

## 홍보 문구 (제안, 150자 안쪽)

```
요즘 10~20대가 쓰는 말, 얼마나 아세요? 한 판 10문제, 1분이면 끝나요. 이번 주 새 말도 들어 있어요. 결과는 친구에게 바로 보낼 수 있어요.
```

## 키워드 (제안, 93바이트)

한글은 한 글자가 3바이트다. 글자 수가 아니라 바이트로 센다.

```
신조어,퀴즈,유행어,줄임말,밈,10대,20대,세대,단어,테스트,말뜻,요즘말
```

앱 이름과 겹치는 낱말은 넣지 않았다(Apple 규칙: 앱 이름을 되풀이하지 않는다).

## 설명 (제안)

```
뭔말이야는 요즘 10~20대가 쓰는 말을 퀴즈로 맞히는 앱이에요.

· 한 판은 10문제, 1분이면 끝나요.
· 뜻을 고르거나, 뜻에 맞는 말을 골라요.
· 답을 고르면 뜻, 예문, 유래를 한 줄씩 보여 줘요.
· 매주 새로운 말이 섞여 나와요.
· 결과는 점수대별 한마디와 함께 친구에게 공유할 수 있어요.
· 월요일 아침에 알려 달라고 하면, 매주 월요일 오전 9시에 알림이 와요. 알림은 폰 안에서만 만들어져요.
· 로그인이 없어요. 열면 바로 풀 수 있어요.

한 번 풀어 보고, 모르는 말이 나오면 카드로 확인해 보세요.

개인정보: 이름, 이메일, 전화번호를 받지 않아요. 쓰임새를 세려고 폰에서 만든 무작위 번호와 행동 기록만 보내요. 자세한 내용은 앱의 개인정보 처리방침을 보세요.
```

광고 빌드를 낼 때만 설명 끝에 「광고가 포함되어 있어요」 한 줄을 더한다(제안). 광고 없는 빌드에는 넣지 않는다.

## 이번 버전 새로운 점 (1.0)

Apple은 첫 버전에는 이 칸을 받지 않는다(출처: 위 도움말 페이지). Google Play 「출시 노트」용 제안:

```
첫 버전이에요. 한 판 10문제로 요즘 신조어를 맞혀 보세요.
```

## 스크린샷

Apple은 iPhone 스크린샷을 한 종류 이상 필수로 받는다. 2026-11-25에 읽은 사양 페이지 기준 필수는 「Dynamic Island(중간)」 크기이고, 세로 1179x2556 또는 1206x2622다. 장수는 1~10장, 알파 채널이 없어야 한다.
출처: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
iPad 스크린샷은 필요 없다. `ios.supportsTablet`이 `false`라서 iPhone 앱으로 낸다(이 줄은 이 앱의 설정 사실이고, iPad 쪽 요구는 이 페이지에서 확인하지 않았다. App Store Connect 화면에서 요구가 뜨는지 본다).
스크린샷은 실제 기기나 시뮬레이터에서 찍어야 한다. 이 저장소에는 아직 없다(David가 찍는다).

## David가 적는다 (이 문서의 빈칸 전부)

- 앱 이름 최종 확정. 상표(KIPRIS) 확인 전이다(`docs/decisions.md`의 「아직 안 정한 것」).
- 지원 URL, 마케팅 URL, 개인정보 처리방침 URL의 도메인.
- 저작권 표기의 이름.
- App Review 연락처(이름, 이메일, 전화번호. 전화는 `+82`처럼 국가 번호가 앞에 붙어야 한다).
- 스크린샷.
- 연령 등급 답과 개인정보 답의 최종 확인(`age-rating.md`, `app-privacy.md`).
